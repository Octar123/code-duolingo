DAILY LESSON · FOUNDATIONS

How does a computer represent numbers?

Computers use bits: tiny pieces of information that have one of two values, 0 or 1. A group of eight bits is called a byte.

Key idea
Binary is a base-2 number system. Each position represents a power of two: 128, 64, 32, 16, 8, 4, 2, 1.
Binary: 0 0 0 0 1 0 1 1\nWeight: 128 64 32 16 8 4 2 1\nValue: 0 0 0 0 8 0 2 1\n\n8 + 2 + 1 = 11

When a bit is set to 1, its weight contributes to the total. When it's 0, it contributes nothing.
